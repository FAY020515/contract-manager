# 合同管理系统 · 使用手册（给同事）

> 适用版本：v2.8.0 及以后　｜　遇到本手册没写的问题，找管理员（目前是 你）

---

## 一、怎么打开

1. 管理员会发给你一个地址，形如 `http://192.168.1.20:3000`
2. 用浏览器（Chrome / Edge 都行）打开这个地址
3. 输入管理员给你开的账号和密码登录

> 程序跑在管理员那台电脑上。那台电脑关机或没开程序时，你的页面会打不开——找管理员。

---

## 二、录一份合同

左侧「合同管理」→ 右上角「新建合同」。

必填只有**合同名称**，其余能填就填：

| 字段 | 说明 |
|---|---|
| 主体公司 | **必选**，选合同属于集团下哪家公司；选项由管理员在「系统设置 → 公司管理」维护 |
| 合同编号 | 选完主体公司会**自动带出**下一个编号（如 `CY-2026-0001`），可手工修改；重复会提示 |
| 合同名称 | 必填 |
| 合同类型 / 部门 | 与「系统设置」里维护的字典一致 |
| 金额 | 只填数字；发生额由下面的收付款记录自动汇总 |
| 到期日期 | 填了才会生成到期提醒 |
| 负责人 | 一般填经办人本人 |

保存后，如果还要传扫描件，在合同详情页「合同附件」处上传（单个文件最大 50MB）。

---

## 三、收付款怎么记

合同详情页 →「收付款记录」→「添加记录」：

- 类型选**收入**或**支出**；状态按实际选 `待收/待付/已收/已付`
- 「已发生」金额只统计 `已收` 和 `已付` 的记录
- 凭证（发票、回单）可以随记录一起上传，也可以事后补

---

## 四、审批信息怎么用

审批本身仍走**纸质审批单**，系统只把结果记下来，方便以后查"这份合同审没审、谁审的"。

在合同详情页的「审批信息」一栏：

1. **改审批状态**：右上角下拉选 `未审批 / 审核中 / 已批准 / 已用印`，选完立即生效
2. 系统会自动记录**改的人和时间**，并写进下方的操作记录
3. **上传审批单**：点「上传审批单」把纸质单的扫描件或照片传上去（可多张）
4. 审批单**单独存放**，不会混进"合同附件"里；删除审批单只有管理员能做

> 忘了标状态不影响录合同，默认就是"未审批"；事后补标也可以。

## 五、到期提醒

左侧「到期提醒」有列表和日历两种视图。合同保存时如果填了到期日期，系统会自动在**到期前 7 天**生成提醒。

> 提醒只在系统里看，不会发微信或短信；建议每天上班先看一眼。

---

## 六、能看到什么、不能做什么

- 每个人都能：新建合同、修改合同、上传附件、记收付款、修改审批状态、上传审批单
- **只有管理员能**：删除合同、删除附件、删除收付款记录、删除审批单
- 所有修改都会留痕：合同详情页底部的「操作记录」写明了谁、什么时候、把哪个字段从什么改成了什么
- 所以请如实操作——改错了就在系统里改回来即可，不需要删记录

---

## 七、别人改了会打架吗

不会丢数据，但可能互相覆盖：两个人同时编辑同一份合同时，后保存的生效。改动内容都会出现在操作记录里。

---

## 八、常见问题

**Q：登录提示"用户名或密码错误"？**
找管理员重置。密码错误次数没有限制，但请勿把账号借给他人——操作记录署的是你的名字。

**Q：为什么我看不到"删除"按钮？**
删除合同、附件、收付款记录、审批单都只有管理员能做。需要删除时找管理员。

**Q：审批状态点错了怎么办？**
直接改回正确状态即可。操作记录里会保留两条（错的和对的），这属于正常的操作痕迹，不用在意。

**Q：合同编号是怎么来的？**
按"所选主体公司的缩写 - 年份 - 序号"自动带出（如 `CY-2026-0001`）。序号按每家主体、每年独立递增；**删掉的编号不会被再次使用**（作废不复用）。

**Q：我手改了编号，再换主体公司为什么没变？**
系统只在你没手动改过编号时才自动带出；改过一次后按你填的保存。想重新带出，把编号清空、重新选一次主体公司即可。

**Q：审批单和合同附件有什么区别？**
审批单是纸质审批流程的凭证（审批单扫描件），单独放在「审批信息」栏；合同附件是合同正本、补充协议这类文件。两者上传方式一样，但分开展示、备份时都会保存。

**Q：附件上传后打不开 / 预览空白？**
先确认文件本身能打开；仍不行请把文件名和合同编号告诉管理员。附件原件存在服务器的 `uploads` 文件夹里，备份时会一起备份。

**Q：页面显示"登录已过期"？**
重新登录即可。系统每天晚上或服务重启后需要重新登录一次，属正常现象。

**Q：能不能导出到 Excel？**
合同列表右上角「导出」；统计页面也能导出图表数据。

**Q：手机能用吗？**
同一局域网内，手机浏览器打开同一地址即可，界面会自动适配，但不保证所有操作都方便。
