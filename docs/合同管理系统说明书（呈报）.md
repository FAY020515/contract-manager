## 一页结论

1. **解决三件事**：合同台账电子化、审批与变更全程留痕、数据有备份不怕丢。
2. **用起来不复杂**：只需在一台电脑上装一次程序，同事用浏览器打开一个内网地址即可使用，**不需要每人安装**。
3. **日常维护成本很低**：每周插一次 U 盘做备份（约 1 分钟），每季度做一次恢复演练（约 10 分钟）。
4. **当前状态**：功能已全部完成并通过内部验证，下一步是在部门电脑上装机试用、按清单验收（约 30 分钟）。

## 一、为什么需要它

目前合同管理的实际情况是：合同正本与审批单散落在档案盒，电子台账靠个人用 Excel 维护，到期时间靠人记，统计汇总靠手工翻表。此前还发生过一次电脑硬盘损坏、合同电子数据全部丢失的情况。

这套系统要解决的不是"把纸变成电子"，而是三件事：**数据不再丢、过程查得到、工作省时间**。

## 二、它能解决什么问题

| 现在的问题 | 系统的解决方式 |
|---|---|
| 合同台账分散在各人手里，查一份合同要问人、翻档案 | 统一录入，按编号、名称、对方单位、金额、部门、负责人、到期日随时检索 |
| 硬盘损坏或误操作导致数据丢失 | 每天自动备份（含附件文件），可一键恢复到任意一次备份；备份失败会在界面上红字提示 |
| 合同改过什么、谁改的，说不清楚 | 每次修改自动记录"改了哪个项目、从什么改成什么"（如：合同金额 8,000 元 → 9,000 元）、操作人和时间 |
| 审批单和合同分开存放，审计时两头找 | 合同的审批状态（未审批/审核中/已批准/已用印）和审批单扫描件直接归档在该合同下，点开即见 |
| 合同到期漏提醒，造成续签或付款逾期 | 录入到期日后自动生成到期前 7 天提醒，首页也有提示 |
| 月度、部门、类型统计靠手工汇总 | 仪表盘与多维度统计图表自动生成，可一键导出 Excel |
| 谁能改、谁能删，没有边界 | 分"管理员/普通用户"两级：普通用户可录入和修改，**删除合同、删除附件、删除审批单、删除收付款记录仅管理员**，删合同还需输入合同编号确认 |

## 三、功能一览

**合同台账**
- 录入、修改、查询、筛选（按编号/名称/对方/金额/日期/状态/部门）
- Excel 批量导入：系统提供标准模板，重复编号会明确提示，日期和金额能自动识别常见写法
- 合同状态：草稿 / 执行中 / 已到期 / 已终止 / 已续签

**附件与审批**
- 合同附件：上传、预览、下载（正本、补充协议等）
- 审批留痕：记录审批状态、经手人与时间；审批单扫描件单独归档，与合同附件分开展示

**收付款**
- 收入/支出记录，状态（待收/待付/已收/已付），自动汇总"已发生金额"
- 付款凭证（发票、回单）可随记录上传

**提醒与统计**
- 到期提醒：列表 + 日历两种查看方式
- 统计：合同总数、金额分布、按类型、按部门、月度趋势，均可导出

**权限**
- 两级角色；操作以本人登录账号署名，无法借他人名义操作
- 最后一位管理员不能被降级、停用或删除，避免系统无人可管

**数据安全**
- 自动备份（每份含数据库 + 全部附件），按设定份数自动轮转
- 一键恢复到任一备份；恢复前自动留一份"恢复前状态"，误操作可再退回
- 完整备份可直接写入 U 盘带走；备份超过 7 天未更新会在界面提醒

## 四、对管理与审计的价值

1. **随时可查**：点开任意一份合同，可以看到谁录入、谁改过、每次改了什么、审批到哪一步、附件与审批单是否齐全。
2. **责任清晰**：所有操作记录署名到人，且以登录账号为准，不由填写人自报。
3. **风险可控**：破坏性操作（删除）只留给管理员并要求二次确认；数据每日自动备份，且备份文件包含附件原件。
4. **省时**：统计与查找由系统完成，不再手工汇总；到期提醒按合同自动生成。

## 五、怎么用、需要投入什么

**使用方式**
- 在一台办公电脑上安装程序（约 2 分钟），该电脑作为"服务器"
- 同事无需安装，用浏览器打开这台电脑的局域网地址即可使用（地址形如 `http://192.168.x.x:3000`）
- 首次使用需做三项准备：设置合同类型与部门、建立同事账号、录入或导入第一批合同

**日常投入**
- 每周：插一次 U 盘点击"完整备份"，约 1 分钟
- 每季度：做一次恢复演练（把数据回到某个备份再确认），约 10 分钟
- 升级：新版本覆盖安装即可，数据不受影响

**不涉及的费用**
- 系统为本部门自行建设，不采购外部软件、不产生订阅费用；备份介质使用现有 U 盘

## 七、名词解释

| 名词 | 解释 |
|---|---|
| 台账 | 记录全部合同基本信息的总账，相当于电子版的合同登记簿 |
| 字段级留痕 | 修改记录精确到"哪一项从什么改成什么"，而不是只记"修改过" |
| 一键恢复 | 选择某一次备份，系统把当时的合同与附件一起还原 |
| 审批单扫描件 | 纸质审批单拍照或扫描后的电子文件，存放在对应合同下 |
| 管理员 | 拥有删除权限、可管理账号与备份的角色；普通用户不具备删除权限 |

## 八、可选与暂不做的功能

| 项目 | 结论 | 理由 |
|---|---|---|
| 到期提醒推送到企业微信/邮件 | 暂不做 | 先观察系统内提醒是否够用；需要时随时可加 |
| 内网传输加密（HTTPS） | 不做 | 需每台电脑装证书并每年续期，维护风险大于收益 |
| 程序自动升级 | 不做 | 仅一台电脑运行，一年升级数次，手动安装即可 |
| 合同审批流程电子化 | 原则上不做 | 纸质审批单已规范运行，系统只归档结果；若将来要求线上流转，另行评估 |
